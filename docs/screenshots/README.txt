截图说明 / Screenshots (v0.3.85)

本目录包含 LLama 万能启动器 v0.3.85 的界面截图，供 README / Release 更新说明引用。

- main.png       主界面（模型选择、运行参数、六套主题入口）
- advanced.png   高级参数 + 多显卡 (Multi-GPU) 展开视图
                 （KV cache K/V 独立量化 -ctk/-ctv、MTP、连续批处理、Flash Attention、上下文预设）
- agent.png      Agent 工具页（OpenCode / Claude Code 等外部工具集成）
- download.png   HF 模型下载页（双列布局、三栏检索、逐文件断点续传）
- updater.png    llama.cpp 更新器页（在线检查并更新 llama.cpp）
- preview.png    命令预览页（生成的启动命令 / .bat 内容预览）
