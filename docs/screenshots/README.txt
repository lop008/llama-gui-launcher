截图说明 / Screenshots (v0.5.13)

本目录包含 LLama 万能启动器 v0.5.13 的界面截图，供 README / Release 更新说明引用。
（v0.5.13 起统一使用「棕色」主题；用 capture/截图脚本重新抓取，1280x1040；
 已做脱敏：本机 IP 显示为示例值 192.168.1.100）

- language.png   多语言菜单展开（v0.5.13 新增：简体中文 / 繁體中文 / English /
                 日本語 / 한국어 / Русский / Español / Français / 跟随系统语言）
- main_en.png    英文界面主视图（v0.5.13 多语言效果展示，棕色主题）
- main.png       主界面（模型选择、运行参数、主题入口；v0.5.01 起含 局域网共享/HTTPS 开关、数据统计按钮）
- advanced.png   高级参数 + 多显卡展开视图
                 （KV cache K/V 独立量化、MTP、Flash Attention、上下文预设，
                  以及 v0.4.25 新增：启用 Jinja 模板 / 思考强度 / 推理预算、
                  启动时检测残留进程 / 端口被占用时建议更换端口）
- pill.png       托盘悬浮小窗（上：收起胶囊，下：悬停展开数据卡片，v0.5.01 新增）
- agent.png      Agent 工具页（OpenCode / Claude Code 等外部工具集成）
- download.png   HF 模型下载页（双列布局、三栏检索、逐文件断点续传）
- updater.png    llama.cpp 更新器页（在线检查并更新 llama.cpp）
- preview.png    命令预览页（生成的启动命令 / .bat 内容预览）

v0.5.13 界面变化：
- 菜单栏新增「语言」菜单：8 种界面语言 + 跟随系统语言，切换确认重启后全界面生效
- 底部按钮改用最小宽度，俄/日/法等长文案完整显示不裁字
- 全部界面截图统一为棕色主题；新增 language.png（语言菜单展开）与 main_en.png（英文效果）
